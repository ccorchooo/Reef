# Mockups

Refined mockups of Reef in the dark tinted theme, using the reference coral scheme. Names, songs and events in `[brackets]` are placeholders. Numbers such as the weather, stats and times are sample values.

- `screens/`: full 1280×800 desktop screens, as PNG.
- `parts/`: close-ups of the Island tabs and Pearl states, as PNG.
- `html/`: the same mockups as static HTML. Open one in a browser to inspect exact sizes, colors and layout in the CSS. They use the fonts in `../fonts` and the logo in `../logo`.
- The original hand-drawn flow is in `../../mockup/` (Excalidraw file and images).
